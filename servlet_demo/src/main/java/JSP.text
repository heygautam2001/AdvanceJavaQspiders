JSP (JavaServer Pages) tags are specialized markup elements in JSP that
enable embedding Java logic and controlling page behavior inside HTML pages.
JSP tags fall into several main categories: directive tags, scripting elements,
standard action tags, and custom tags, each serving specific roles in JSP development.


Scripting Elements
Scripting elements allow embedding Java code directly in the JSP page.

Declaration tag (<%! ... %>): Declares variables and methods.

Scriptlet tag (<% ... %>): Contains Java statements.

Expression tag (<%= ... %>): Evaluates and outputs the value.

Example:

text
<%! int count = 0; %>           <!-- Declaration -->
<% count++; %>                  <!-- Scriptlet -->
Welcome! You are visitor number <%= count %> <!-- Expression -->
